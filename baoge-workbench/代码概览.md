# 宝哥工作台 · 小程序代码概览

> 路径：`个人成长工作台小程序/baoge-workbench/`
> 版本：v0.9.0（README 标注）｜AppID：`wx36a85277cc9b3cb6`｜基础库 `3.4.0`
> 定位：个人自用的「成长管理系统」——首页「今日待办」为执行台，背后挂读书 / 健身 / 学习三大计划；完成后沉淀为书脊墙与技能图鉴。
> 代码总量：约 **9389 行**（含 1209 行回归测试），纯原生小程序，**无 npm 依赖、无分包、无自定义组件**。

## 一、技术栈与架构特征

| 维度 | 结论 |
|---|---|
| 框架 | 微信原生小程序（WXML / WXSS / JS），非 Taro/uni-app |
| 后端 | **纯本地优先**：数据全部存 `wx.setStorageSync`，不开云开发也能跑全部功能 |
| 网络 | 无 `wx.request`（除云同步预留通道外，无任何域名请求）——离线可用 |
| 自定义组件 | **无**（所有复用 UI 走 `app.wxss` 全局类 + 各页内联 WXML） |
| 分包 | **无**（主包即全部，当前体量远小于 2MB 限制，无需拆分） |
| 测试 | 自带 Node 回归测试（mock `wx`/`Page`/`App` 桩），README 称 **30/30 通过**，实际测试文件已增长到 **29 大项、1209 行** |
| 配置 | `lazyCodeLoading: requiredComponents`（按需注入）、`style: v2`、URL 校验关闭（`urlCheck:false`，便于本地调试） |

**关键设计原则（来自 `app.js` 注释）**
1. 本地存储优先——不配服务器、不买域名、断网可用。
2. 云同步可选——`settings.cloudSync` 开启后写云数据库，但当前「我的」页云备份入口**已回退为禁用占位**（点一下弹「功能升级中」），未开放下行拉取。
3. 全局一份配置：所有页面通过 `getApp().globalData` 共享主题/配色/源标记。

## 三、数据层（存储模型）

所有数据落在 `wx.setStorageSync`，key 集中在 `utils/storage.js` 的 `KEYS`：

| storage key | 说明 | 核心字段 |
|---|---|---|
| `baoge:books` | 在读书籍 | `_id,title,author,progressType(chapter/page/percent),status,color,startDate,records[],deadline,cover,autoTodo` |
| `baoge:bookRead` | 已读书（书脊墙） | 同上 + `finishedAt/finishedDate,rating,review,tags` |
| `baoge:skills` | 在学技能 | `_id,name,icon,goal,stages:[{name,done,doneAt,doneDate,logs[]}],color,cycleDays` |
| `baoge:skillAchieved` | 已达成（图鉴） | 同上 + `achievedAt` |
| `baoge:workouts` | 训练记录 | `_id,name,date,items:[{name,target,sets:[{reps,weight}],done}],completed,startedAt,completedAt,durationMin,volume` |
| `baoge:body` | 体重/体脂 | `{date,weight,fat}` |
| `baoge:todos` | 待办 | `_id,date,source(manual/reading/learning/fitness),sourceKey,sourcePlanId,title,desc,done,important,skipped` |
| `baoge:countdown` | 倒计时 | `_id,name,date,annual,createdAt,lunar` |
| `baoge:templates` | 健身自定义/收藏模板 | `{name,items[]}` |
| `baoge:settings` | 设置 | `lastBackupAt,dark,cloudSync(预留)` |

**统一接口**：业务页面只调 `storage.list/add/update/remove(key, ...)`，不直接碰 `wx.setStorageSync`，便于后续替换底层（云/本地切换）。

## 四、核心业务逻辑（最该先读懂的三块）

### 1. 派生引擎 `utils/derive.js` ★
把三大模块的计划「自动派生」到首页今日待办，是首页的灵魂。
- `deriveDailyTodos(targetDate?)`：按查看日派生该日待办。
  - **读书**：仅真实当天、且书设了 `autoTodo` + `deadline` 且未过期，才聚合一条「读《A》《B》」待办（`sourceKey:'reading:today'` 恒定，多本不各自出现）。
  - **学习**：**已取消**派生（学习计划跟进统一在「在学」页，不污染首页）。
  - **健身**：仅「未完成的、计划日 === target」的训练派生一条 `planned` 待办（未来计划日在其对应日期才出现）。
  - 落库时会做**孤儿清理**（训练已删 / 错过过去的 planned 待办）与**已完成保留**（`&& !t.done` 守卫，避免下一轮派生抹掉完成态）。
- `completeDerived(todoId)`：勾选派生任务时回写计划进度。
  - 读书：章节/页/百分比 +1，满则推 `bookRead`（上书脊墙）。
  - 学习：当前阶段标 done，全 done 推 `skillAchieved`（进图鉴）。
  - 健身：标记训练 `completed`。

> ⚠️ 踩坑经验（见 `.workbuddy/memory`）：回写「计划日待办」**绝不能加 `t.date===今天`** 这类日期锁——提前/延后完成都会因匹配不到让 derive 误清。按 `sourcePlanId` 全量匹配最稳。

### 2. 备份恢复 `utils/backup.js`
- 快照：`buildSnapshot()` 导出 8 类数据（不含 settings）为带 `version/app/exportedAt` 的 JSON。
- 导出：`exportAndShare()` → 写文件 + `wx.shareFileMessage` 发微信（真机专用，开发者工具降级剪贴板）；`copyToClipboard()` 复制全文。
- 恢复：`importFromFile()`（`wx.chooseMessageFile` 从聊天选文件）/ `importFromClipboard()`，覆盖式写入。
- **恢复前自动先备份到剪贴板**（`profile.autoBackupThen`）防误覆盖丢数据。

### 3. 日期 / 农历 / 进度模型 `utils/util.js`
- 日期：`todayISO/addDaysISO/diffDays/isPast/countdownDays` 等。
- **农历**：`solarToLunar/lunarToSolar`（1900–2100，含闰月）。曾因时区偏移（沙箱 `GMT+0805`）系统性早 1 天，已改用 `Date.UTC` 全程换算修掉，并有 33 个春节锚点 + 796 次往返一致性测试覆盖。
- **进度统一模型**：`progressOf(b)` 返回 `{cur,total,percent,done}`，支持章/页/百分比三单位共存；`stepProgress(b)` 步进一节。

## 五、各页面功能模块

### 今日 `pages/index/`（执行台，逻辑最重）
- 待办列表：来源标记 + 分组（按来源 / 未完成置顶）+ 重要星标 + 完成激励动效。
- **日期切换跨天**：顶部日期栏可 ‹ › 切换；点日期标签弹「chip 快捷选择」（−7~+14 天，有待办日绿点标记）+ 原生 picker 跳转任意日。
- 记一笔：单表单（名称/详情/日期/重要星标）；日期 = 昨天~+8 共 10 天连续芯片横滑 + 自定义 picker（覆盖窗口外）。
- 倒计时卡片：公历月历点选（过去禁用）/ 农历三级联动 + 每年重复；同步显示农历。
- 本周速览（v0.10 重设计）：三卡统一为自然周（周一起）"本周真实发生"口径——读书=翻阅天/完本数、健身=完成次数/达标天数(目标5天)、学习=点亮阶段/达成技能(目标2阶段)，进度条分母统一为周目标或周内已过天数。
- 周待办：固定 7 天窗口（今天−4 ~ 今天+2），红(未完成)/绿(已完成)双色比例条。
- 空状态：每日轮换激励语 + 去三模块建计划引导。

### 读书 `pages/reading/`（书架 + 书脊墙）
- 书架 Tab：加书单表单（书名/作者/单位/总量合并）、书名查重、三单位进度、记进度（滑块定位 + 读了一节）、目标读完日 + 自动待办门禁（需先设 deadline）、阅读记录（改名后可删、50 条上限覆盖最早保留 createdAt）、书评多行+标签、书墙排序/作者筛选/搜索。
- 书脊墙 Tab：长按弹详情、评分（必填，进度满 100% 才弹上墙界面）、书评选填、打星。
- 导出读书笔记 Markdown（`exportNotes`）；书摘本功能已下线。

### 健身 `pages/fitness/`（训练 + 身体）
- 训练视图：8 天日期芯片（今天起~+7，默认明天）、三分化(PPL) + 空新手训练模板、自定义/收藏模板(`baoge:templates`)、动作选择弹层（搜索+自定义，修复了 `showActionSheet` 21 项超上限静默失败）、逐组步进录入（次数±1/重量±2.5kg）、组间休息 90s 计时、训练自动计时（开始/结束/共）、PR 破纪录 toast。
- 历史训练专区：已完成收纳、默认折叠。
- 身体视图：体重/体脂记录 + `picker-view` 滚轮（锁今天及之前）+ Canvas 趋势曲线（1/3/6月/全部，同日去重，>60 点抽稀）。

### 学习 `pages/learning/`（技能 + 图鉴）
- 单表单创建：14 个图标（两排，知识/生活，去掉图书📖/健身🏋）、名称/目标/周期/阶段（输入即自动新增空阶段）、阶段模板库一键套用。
- 阶段圆圈点灯、里程碑备注、上移/下移/重排、长按改名/删除。
- 成长记录时间线（50 条上限）、目标周期/每周节奏、达成回顾卡、图鉴长按删除、达成分享卡（文字版）、成长笔记导出 Markdown。

### 我的 `pages/profile/`（统计 + 备份 + 设置）
- 数据汇总 + 存储占用显示。
- 备份：一键备份发微信（推荐）/ 导出成长报告（月/年/全部，长图优先 + HTML 降级）/ 复制完整 JSON；上次备份 X 天前、超 7 天变黄 + 立即备份大按钮。
- 恢复：从微信文件 / 从剪贴板（恢复前自动备份）。
- 暗色模式开关（`settings.dark`，即时换肤）；云备份禁用占位；清空数据危险区。
