## 三、功能模块详细分析

### 3.1 今日首页 (index)

**核心能力:**
- **待办系统**: 手动待办(名称/详情/日期/重要星标) + 派生待办(读书/学习/健身自动聚合)
- **周待办**: 固定7天窗口(昨天→今天→后5天)，统一胶囊轨道图标，点击跳转
- **倒计时**: 一次性/每年重复事件提醒
- **成长速览**: 读书/健身/学习三维度本周进度概览
- **日期导航**: 左右箭头切日 + 日历picker直接选日 + 一键回今天

**数据流:**
```
用户操作 → index.js handler → storage.js (读写KV)
                              ↘ derive.js (计划→待办派生)
                              ↘ backup.js (快照)
```

### 3.2 读书 (reading)

**核心能力:**
- **书架/书墙**: 在读/已读双视图，章/页双进度模式
- **记进度**: 定位滑块(去计时合并版)
- **读书记录**: 折叠展示(默认3条)+查看全部+滚动
- **添加弹层**: 书名/作者/单位/总量/配色(.sheet样式已补齐)

### 3.3 健身 (fitness)

**核心能力:**
- **模板系统**: 9套预设(新手循环/三分化PPL/五分化Bro) + 自定义 + 用户收藏
- **计划日期**: 今天起连续8天芯片选择
- **默认周期**: 新建训练默认7天周期，从明天起算
- **组间休息计时器**: 动作间倒计时
- **派生集成**: 当天训练自动进今日待办(非planned)，未来起始显示计划预览(planned)

### 3.4 学习 (learning)

**核心能力:**
- **技能库**: 16个分类图标(语言/编程/音乐/厨艺/棋类/摄影等)
- **阶段打卡**: 多阶段技能追踪，每阶段独立doneAt
- **图鉴系统**: 达成徽章 + 长按删除 + 详情时间线(仅日期，去小时)
- **滚动容器**: 列表和详情均支持上下滚动

### 3.5 我的 (profile)

**核心能力:**
- **备份/恢复**: JSON快照 → 剪贴板 → 导入恢复(含防覆盖先备)
- **存储统计**: 各数据表占用可视化
- **暗色模式**: 全局主题切换(导航栏+背景+页面class)
- **版本信息**: 当前版本号展示

## 五、技术债务清单

| 项目 | 影响 | 建议 |
|------|------|------|
| 无构建步骤/npm | 无法使用第三方包、无法shaking dead code | v1.x考虑引入webpack/mpvue |
| 存储无Schema | 所有数据自由格式，字段变更无迁移机制 | 加一层 model 验证层 |
| 测试仅覆盖happy path | 边界条件(空数据/超长文本/特殊字符)未覆盖 | 补充边界用例 |
| 无错误边界 | 单页JS报错会导致整个Page白屏 | 加 try-catch 守护关键路径 |
| color.js 重复色 | bookColors 有重复值 | 去重 |
