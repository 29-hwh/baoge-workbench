# 本周待办模块 · 优化修改建议

> 适用范围：个人成长工作台小程序 · 今日首页「本周待办」竖条卡片
> 本文档含三部分：当前问题诊断、已落地改进、可继续打磨方向（交互逻辑 / 滑动范围 / 视觉布局）

---

## 一、当前问题诊断

| 问题 | 原实现表现 | 影响 |
|------|-----------|------|
| 与"今日"脱钩 | 固定显示本周一~周日 7 天，今日可能落在任意一列 | 用户找不到"今天在哪" |
| 不可连续查看 | 只能点某天切主待办，周卡片本身不移动 | 复盘/规划相邻日需反复点 |
| 图标大小不一 | 无任务日仅底部 12rpx 浅灰点，有任务日是 56rpx 绿填充 | 视觉上"高低胖瘦"不一致 |
| 范围受限 | 只能看当前自然周 | 半个月前复盘 / 半个月后规划够不着 |

---

## 二、交互逻辑改进（本轮已落地）

### 1. 窗口模型：今日默认居中
- 固定显示 **今日−3 ~ 今日+3** 共 7 天，**今日恒居第 4 列并高亮**（红调）。
- 不再绑定"周一~周日"，任何一天打开都先看到今天在中间。

### 2. 切换方式：手势 + 箭头
- **左右滑动**（主）：左滑看未来、右滑看过去，每次平移 1 天；滑动阈值 40px。
- **左右箭头**（备）：卡片上方 `‹ ›` 按钮，同逻辑。
- **边界约束**：中心日期 ∈ `[今日−15天, 今日+15天]`（前推 / 后推半个月），到边界轻提示不再移动。

### 3. 点选某天：联动主待办
- 点轨道任意一天 → 主待办列表切到该日（历史 / 预定 / 今日三态自动切换），周卡片同步高亮选中边框。

### 4. 范围提示
- 卡片上方显示当前窗口日期区间，如 `9月1日 ~ 9月7日 · 左右滑动切换`，随时知道看到哪段。

---

## 三、滑动范围方案

**短期（已做）**：±15 天窗口滑动，覆盖"半个月前复盘 / 半个月后规划"两大高频场景，足够日常使用且不会让卡片无限拉长。

**可选增强（后续迭代）**：
- **一键归位**：当窗口偏离今日时，浮出"回到今天"按钮；今日居中时自动隐藏，减少干扰。
- **速度 / 双指跨跳**：快速滑动或双指手势支持一次跨周 / 跨月，长跨度规划更高效。
- **月历视图升级**：若未来要做整月视图，可将 7 格窗口升级为 `scroll-view` 连续横向滚动 + 吸附分页，中心格始终对齐"今日 / 选中日"。
- **自然周 / 自然月快捷**：长按某天快速跳到该日所在自然周或自然月，兼顾"周复盘"习惯。

## 四、视觉布局改进

### 1. 图标统一（已做，根治"大小不一"）
- 有任务 / 无任务轨道统一为 **24rpx 宽、56rpx 高胶囊形**。
- 无任务日改为**占满整条轨道的浅灰胶囊**，仅颜色区分（不再只是底部一小段灰点）→ 有 / 无任务日等宽等高，纯靠颜色与填充高度表达状态。

### 2. 中心格标记
- 窗口中心格（非今日时）浅灰底 + 星期加粗，提示"当前查看窗口的中心位置"。

### 3. 完成度表达
- 有任务日：浅红底（待完成轨道） + 绿色填充，填充高度 = 当日完成率 %。
- 无任务日：整条浅灰，语义清晰、不抢眼。

### 4. 数字徽章
- 有任务：显示当日待办条数；无任务：显示弱化"·"，不撑宽、不喧宾夺主。

### 5. 配色层级
- 今日 = 红调（强调）；中心 = 中性灰（定位）；常规 = 浅色（背景）。三层分明，信息一眼可读。

---

## 五、可继续打磨的点

1. **滑动手势增强**：增加"跨周 / 跨月"快捷（速度阈值或双指），长跨度不再一天天滑。
2. **激励指标**：周完成率旁增加"连续打卡天数"，强化坚持正反馈。
3. **暗色模式复核**：暗色下轨道红 / 灰对比度需二次验证，避免低对比看不清。
4. **无障碍**：轨道增加 `aria-label`（日期 + 完成数），方便读屏。
5. **空状态引导**：整窗口 7 天全无任务时，给出"定个小目标？"轻引导而非纯空白。
