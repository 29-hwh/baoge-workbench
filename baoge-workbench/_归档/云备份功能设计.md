### 云数据库集合 `baoge_backups`
```
{
  _openid,            // 微信云开发自动注入（无需自建登录）
  app: 'baoge-workbench',
  version: 1,
  exportedAt: Number,
  size: Number,       // JSON 字节数
  device: String,     // systemInfo.model 截断，多设备区分
  latest: Boolean,    // 仅最新一条 true
  data: { books, bookRead, skills, skillAchieved, workouts, body, todos, countdown }
}
```
> 写入策略：先把历史 `latest:true` 全部置 `false`，再 `add` 新记录 `latest:true`（用 `db.command` 批量写保证原子）。

## 三、冲突与一致性

- **策略 v1：Last-Write-Wins**（按 `exportedAt` 取最新）。不做自动合并，避免误覆盖。
- 恢复前**强制本地自动备份**（复用 `profile.autoBackupThen`），用户随时可找回。
- 多设备：同一 OPENID 共享；UI 展示「云端时间 / 本地修改时间 / 设备」，由用户判断恢复哪份。
- 数据全部存于**用户自有云环境**，符合个人数据合规。
