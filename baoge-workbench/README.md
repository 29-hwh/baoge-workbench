## 一、数据存在哪（重要）

**数据只存在你手机本地**（`wx.setStorageSync`）。这意味着：

- ✅ 不需要任何后端、不花一分钱、不用备案域名
- ✅ 打开即用，断网也能正常记录
- ⚠️ **换手机 / 清微信缓存 / 卸载重装 → 数据会没**

所以 v0.2.0 补了一套**备份闭环**（见第三节）。**建议每周备份一次。**

### 关于云同步

代码里（`utils/storage.js`）预留了云开发的上行通道，但**下行拉取未完成**，
因此「我的」页**没有开放**云同步开关——避免误以为开了就安全了。

将来若要做真正的多端同步，需要补：
1. 启动时从云拉取 → 与本地按 `updatedAt` 合并
2. 冲突策略（同一条数据在两台设备都改过）
3. 增量同步 + 失败重试队列

个人自用场景优先级低，**先靠备份方案即可**。

## 二、立即上手（5 步跑起来）

1. **打开微信开发者工具**，选择"导入项目"
   - 项目目录：选 `baoge-workbench/`
   - AppID：点"使用测试号"即可（无 AppID 也能跑）
2. 工具自动编译，进入模拟器
3. 默认进入「今日」页，数据为空
4. **先建计划**：
   - 切到「读书」→ 右下角 + → 加一本书（如《三体》→ 总章节 28）
   - 切到「学习」→ 右下角 + → 加技能 → 拆 2-3 个阶段
5. 切回「今日」→ 读书和学习各派生一条待办，点勾完成：
   - 读书点一次 → 章节 +1；读到最后 → 自动上书脊墙
   - 学习点一次 → 阶段 ✓；最后阶段完成 → 徽章进图鉴
6. 健身同理：新建训练 → 加动作 → 录组数

> ⚠️ **数据修复提醒（v0.2.1）**：早期版本存在一个存储 key 传参 bug，可能导致
> 在读书/学习/健身页手动录入的数据落不到首页待办派生的数据源。
> **如果你此前已在模拟器/真机上录过书或技能，请到「我的」→ 清空数据，再重新录入一次**，
> 确保从干净起点开始，三模块待办才能正确出现在首页「今日」。

## 三、备份与恢复（核心，务必看）

### 备份：发到微信「文件传输助手」

「我的」→ **备份并发到微信** → 生成 `宝哥工作台备份_20260903.json` →
弹出微信好友列表 → **选「文件传输助手」** → 发送完成。

这样做的三个好处：
- 电脑上打开微信就能收到这个文件，**"偶尔电脑看"的需求直接满足**
- 换手机时，在新手机上从聊天记录里选这个文件恢复
- 数据始终在你自己手里，不经过任何第三方服务器

> ⚠️ 开发者工具模拟器里不支持发文件，会自动降级为"复制到剪贴板"。
> **真机预览时才是完整体验。**

### 备份：复制进度速览（推荐给"只想看看"）

「我的」→ **复制进度速览** → 得到纯文字：

```
宝哥工作台 · 进度速览
2026-09-03

【在读 2 本】
  · 三体  11/28 章  39%
  · 置身事内  12/12 章  100%

【在学技能 1 项】
  · Swift  1/2 阶段  下一步：视图
```

粘贴到「文件传输助手」，电脑上直接读文字，不用打开任何文件。

### 恢复

| 入口 | 用途 |
|---|---|
| **从微信文件恢复** | 在聊天记录里选中备份的 json（推荐，最稳） |
| **从剪贴板恢复** | 先复制备份全文，再用这个 |

恢复是**覆盖式**的——会清掉当前全部数据再写入，操作前有确认弹窗。

## 五、数据模型

| 存储 key | 结构 | 说明 |
|---|---|---|
| `baoge:books` | `{_id, title, author, progressType, status, color, startDate, records:[], deadline, cover}` | 在读书：chapter 用 totalChapters/currentChapter；page 用 totalPages/currentPage；percent 用 progressPercent；records 想法归档；deadline 目标读完日；cover 封面本地路径 |
| `baoge:bookRead` | 同上 + `finishedAt/finishedDate, rating, review` | 已读书（书脊墙，含上墙时带走的 records 想法） |
| `baoge:skills` | `{_id, name, icon, goal, stages:[{name,done,doneAt}], color}` | 在学技能 |
| `baoge:skillAchieved` | 同上 + `achievedAt` | 已达成技能（图鉴来源） |
| `baoge:workouts` | `{_id, name, date, items:[{name, target, sets:[{reps,weight}]}], completed, completedAt}` | 训练记录 |
| `baoge:todos` | `{_id, date, source, sourcePlanId, title, desc, done}` | 待办（date 决定归属哪天，可预定未来） |
| `baoge:countdown` | `{_id, name, date, annual, createdAt}` | 倒计时（annual=true 每年一次） |
| `baoge:settings` | `{lastBackupAt, ...}` | 配置 |

**时间维度能力（v0.3）**
- 待办添加时可选日期：今天/明天/后天/自定义（自定义禁选过去日期）
- 首页顶部可左右切换日期，跨天查看「预定未来」待办（今天视图实时派生计划任务）
- 今日页新增「倒计时」卡片：支持节日/纪念日（每年一次）与自定义事件
- 读书：加书自动记开始日期；读完可回填过去日期（书脊墙按回填时间排序）

**派生规则（`utils/derive.js`）**
- 读书 `totalChapters > 0` 且未读完 → 派生"读到第 X 章"
- 学习有未完成 stage → 派生"第 N 阶段 · 名称"
- 健身当天有未完成训练 → 派生"X 个动作"
- 手动任务不参与派生，原样保留

**完成回写（`completeDerived`）**
- 读书：章节 +1，读满则推入 `bookRead`（上书脊墙）
- 学习：当前 stage 标 done，全 done 则推入 `skillAchieved`（进图鉴）
- 健身：标记训练 completed

## 九、调试常见问题

- **图标不显示**：检查 `assets/tabbar/` 下是否 10 个 PNG；重跑 `python3 tools/gen_icons.py`
- **派生任务不出来**：先去读书/学习页建计划，派生基于计划存在
- **发文件按钮没反应**：模拟器不支持，用真机预览
- **恢复后数据没变**：确认选的是本工具导出的 json（文件名含"宝哥工作台备份"）
- **数据没了**：本地存储的固有限制，这就是为什么必须定期备份
