## Round 16 日期选中态对比度修复
- 根因（非纯配色问题，是**优先级冲突**）：`.date-chip.future .dc-label`(0,2,1) 声明在 `.date-chip.on .dc-label`(0,2,1) 之后 → 选中未来日期时主文字被刷成 `--c-text-2` 灰，灰字/紫底(#534AB7) 对比仅 **1.07:1**，等于隐形。
- 修复（仅改选中态，未选中/今日标记/禁用态不动）：新增 (0,3,1) 选中态规则 `color:#fff;font-weight:600`（浅色 6.93:1）；`.theme-dark .date-chip.on` 叠 `rgba(0,0,0,0.42)` 压暗底色（暗色白字 3.3:1 → 7.87:1）；`.cal-cell.sel` 淡底由硬编码蓝改主色系，暗色沿用全局暗色规范（主色 18% 底 + #B6ACFF 字，4.53 → 6.09:1）。
- 经验：**小程序/ CSS 中"状态修饰类"(future/today)与"选中态类"(on)同优先级时，声明顺序决定胜负**——选中态必须用更高特异性选择器（多一个类）提权，否则会被后写的修饰色覆盖。改配色前用脚本按 WCAG 公式算对比度，避免"以为改好了其实更糟"（本次暗色日历底一度从 4.53 降到 3.38，靠计算才发现）。
- 改动文件：仅 `pages/index/index.wxss` + `代码概览.md`。回归 232/232 全绿。
